# IIT Jodhpur Course Resources

Course materials are organized by academic year and course. Follow the existing semester and professor folders within each course.

## Repository structure

```text
1_First_Year/CourseCode/semester_professor/
2_Second_Year/CourseCode/semester_professor/
3_Third_Year/CourseCode/semester_professor/
4_Fourth_Year/
B24/
docs/
```
